# 📚 Biblioteca Digital API

API REST para gerenciamento e catálogo de livros de uma biblioteca digital.

---


## 🚀 Tecnologias utilizadas

- **Node.js** — ambiente de execução JavaScript.
- **Express** — framework para criação da API REST.
- **MongoDB** — banco de dados NoSQL.
- **Mongoose** — modelagem e interação com o banco de dados.
- **Swagger** — documentação interativa da API.


---


## ✨ Funcionalidades

- Cadastro de novos livros.
- Listagem e consulta de livros por ID.
- Atualização parcial das informações de um livro.
- Exclusão de livros.
- Filtros por título, autor e gênero.
- Paginação dos resultados.
- Ordenação por título, autor, ano ou gênero.
- Documentação interativa com Swagger UI.


---


## ⚙️ Como Executar o Projeto Localmente

### Pré-requisitos

- [Node.js](https://nodejs.org/)
- [MongoDB](https://www.mongodb.com/)
- [Git](https://git-scm.com/)

1. Clone o repositório:
```
git clone https://github.com/leticia-aragao/api-livraria.git
```

2. Acesse a pasta do projeto:
```
cd api-livraria
```

3. Instale as dependências:
```
npm install
```

5. Inicie o servidor:
```
npm start
```

A API estará rodando em: http://localhost:3000/api


---


## 📖 Documentação da API

A documentação interativa completa dos endpoints está configurada e disponível localmente através do Swagger UI. Após iniciar a aplicação, acesse:
